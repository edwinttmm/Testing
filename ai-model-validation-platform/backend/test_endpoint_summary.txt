ENDPOINT DETAILS:
=================
POST /api/test-sessions/validate-ground-truth
Request:  {"videoIds": ["uuid1", "uuid2", ...]}
Response: {
  "hasIssues": boolean,
  "videosWithoutGt": ["uuid"],
  "gtCounts": {"uuid": count},
  "videoDetails": [{
    "videoId": "uuid",
    "gtCount": 10,
    "hasGroundTruth": true,
    "status": "ready"
  }],
  "totalVideos": 3,
  "readyVideos": 2,
  "validationTimestamp": "ISO8601"
}

POST /api/test-sessions?force_start=true
Query Params: force_start (boolean, default: false)
- force_start=false: Validates GT, fails if missing
- force_start=true: Skips validation, logs warning
