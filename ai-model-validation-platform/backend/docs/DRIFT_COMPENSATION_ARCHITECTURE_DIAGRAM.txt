║                          1. CLOCK SYNCHRONIZATION                           ║
╚═════════════════════════════════════════════════════════════════════════════╝

┌──────────────┐                                    ┌──────────────┐
│   Browser    │                                    │   Backend    │
│  (Client)    │                                    │  (Server)    │
└──────┬───────┘                                    └──────┬───────┘
       │                                                   │
       │  T1: PING (performance.now())                    │
       ├─────────────────────────────────────────────────>│ T2: Received (time.perf_counter())
       │                                                   │
       │                                                   │
       │  T3: PONG (T2, T3)                               │
       │<─────────────────────────────────────────────────┤ T3: Sent (time.perf_counter())
       │ T4: Received (performance.now())                 │
       │                                                   │
       └───────────────────────────────────────────────────┘

       Calculate:
       RTT = T4 - T1
       Clock Offset (θ) = ((T2 - T1) + (T3 - T4)) / 2

       Accuracy: ±5ms (LAN), ±10ms (WAN)

       │                                  │ T_command_sent               │ (device clock)
       │                                  │ = 1.200 s                    │ = 1.200 s
       │                                  │                              │
       │                                  │<─────────────────────────────┤
       │                                  │ ACK + Timestamp              │
       │                                  │                              │
       │<─────────────────────────────────┤                              │
       │  SYNC_STATUS                     │                              │

       Drift Calculation:
       T_video_start_backend = 1000.0 ms + 50 ms (clock offset) = 1050 ms = 1.050s
       T_labjack_start = 1.200s
       Drift = (1.200 - 1.050) * 1000 = 150 ms

╔═════════════════════════════════════════════════════════════════════════════╗
║                      3. TIMESTAMP COMPENSATION                              ║
╚═════════════════════════════════════════════════════════════════════════════╝

Input: Raw LabJack Detection
  T_detection_raw = 2.500 s (backend clock domain)

Step 1: Convert video start to backend clock
  T_video_start_backend = T_video_start_browser + clock_offset
  T_video_start_backend = 1000.0 ms + 50 ms = 1050 ms = 1.050s

Step 2: Compensate detection to video timeline
  T_detection_compensated = (T_detection_raw - T_video_start_backend) * 1000
  T_detection_compensated = (2.500 - 1.050) * 1000 = 1450 ms

Output: Compensated Detection
  Detection occurred at 1450 ms in video timeline ✓

╔═════════════════════════════════════════════════════════════════════════════╗
║                      4. GROUND TRUTH MATCHING                               ║
╚═════════════════════════════════════════════════════════════════════════════╝

Ground Truth Events:
  GT1: Object appears @ 1400 ms (video timeline)
  GT2: Object appears @ 2000 ms (video timeline)

Compensated Detections:
  Detection1: @ 1450 ms (video timeline)
  Detection2: @ 2050 ms (video timeline)

Matching Algorithm (tolerance = 50 ms):
  Detection1 → GT1: |1450 - 1400| = 50 ms ✓ MATCH (within tolerance)
  Detection2 → GT2: |2050 - 2000| = 50 ms ✓ MATCH (within tolerance)

Results:
  True Positives: 2
  False Positives: 0
  False Negatives: 0
  Precision: 100%
  Recall: 100%
  Mean Timing Error: 50 ms

╔═════════════════════════════════════════════════════════════════════════════╗
║                        6. PRE-START BUFFER STRATEGY                         ║
╚═════════════════════════════════════════════════════════════════════════════╝

Problem: Network delay causes LabJack to start 50-200ms late
Solution: Start LabJack BEFORE video starts

Timeline:

  -300ms         0ms (Video Start)       +50ms           +1000ms
    │             │                       │               │
    └─────────────┼───────────────────────┼───────────────┤
                  │                       │               │
    LabJack       │                       │               │
    Starts        │                       │               │
    Monitoring    Video                   First           Detection
    (300ms early) Playback                Detection       Captured
                  Begins                  Expected        

Post-Processing:
1. Trim detections before t=0 (video start marker)
2. Compensate all remaining detections to video timeline
3. Match with ground truth

Guarantee: ZERO detection loss, even with 200ms network delay

╔═════════════════════════════════════════════════════════════════════════════╗
║                       9. TROUBLESHOOTING QUICK REF                          ║
╚═════════════════════════════════════════════════════════════════════════════╝

Problem: High Drift (>500ms)
  Check:
  ✓ Network latency: ping <backend-host>
  ✓ LabJack USB connection
  ✓ System CPU/memory load
  Fix: Use wired connection, check USB cable, reduce system load

Problem: Poor Clock Sync (RTT >100ms)
  Check:
  ✓ WebSocket transport type
  ✓ Network path (traceroute)
  ✓ Server processing time
  Fix: Increase sample count, use wired network, optimize server

Problem: Low Spec Compliance (<95%)
  Check:
  ✓ Drift distribution (SQL queries)
  ✓ Recent system changes
  ✓ Problem tests/devices
  Fix: Analyze trends, identify root cause, apply targeted fixes
