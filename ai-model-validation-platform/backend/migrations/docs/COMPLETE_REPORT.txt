  NEW FIELD:

      - Indexed for performance
      - Tracks T1-T0 presentation delay in milliseconds

  NEW INDEXES:
    + idx_sequence_video_results_playing_delay
      - Single column index on frontend_playing_delay_ms
      - Enables fast sorting/filtering by delay

    + idx_sequence_video_results_delay_status
      - Composite index on (frontend_playing_delay_ms, video_status)
      - Optimizes delay+status queries

TABLE: test_sessions
  NEW FIELD:
    + evaluation_details JSON NULL
      - Indexed (GIN for PostgreSQL)
      - Stores detailed evaluation metrics and reasoning
      - Backfilled with migrated legacy data

  NEW INDEXES:
    + idx_test_sessions_dual_eval
      - Composite index on (accuracy_result, latency_result, overall_test_result)
      - Enables efficient dual-evaluation filtering

    + idx_test_sessions_evaluation_details
      - GIN index on evaluation_details (PostgreSQL only)
      - Accelerates JSON query performance
