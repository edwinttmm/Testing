## Data Flow Comparison

### Current (Metadata-Based):
```
Detection Event
    │
    ├─> Read sequence_metadata.current_video_id ❌ Can be stale
    │
    └─> Store with video_id from metadata → WRONG VIDEO POSSIBLE
```

### Proposed (Timestamp-Based):
```
Detection Event (timestamp=15.0)
    │
    ├─> Query SequenceVideoResult WHERE start_time <= 15.0 AND end_time > 15.0
    │   (Immutable database records) ✅
    │
    ├─> Find: video_id="bbb"
    │
    ├─> Cross-validate with metadata (if available)
    │   ├─> Match: confidence=1.0 ✅
    │   └─> Mismatch: confidence=0.9, log warning 🚨
    │
    └─> Store with computed video_id="bbb" → CORRECT VIDEO GUARANTEED
```

## Video Transition Sequence

### Current System (Manual Update):
```
t=0s   ┌─────────────┐
       │  Video A    │  sequence_metadata.current_video_id = "aaa" ✅
       │  Plays      │
t=10s  │             │  Detection → video_id="aaa" ✅
       │             │
t=12s  └─────────────┘  video_ended("aaa")
         │
         │ UPDATE sequence_metadata.current_video_id = "bbb" ❌ FAILS
         │
       ┌─────────────┐
       │  Video B    │  sequence_metadata.current_video_id = "aaa" ❌ STALE!
       │  Plays      │
t=15s  │             │  Detection → video_id="aaa" ❌ WRONG!
       │             │
t=20s  │             │  Detection → video_id="aaa" ❌ WRONG!
       └─────────────┘
```

### Proposed System (Timestamp-Based):
```
t=0s   ┌─────────────┐
       │  Video A    │  SequenceVideoResult: start_time=0.0 ✅
       │  Plays      │
t=10s  │             │  Detection at t=10.0
       │             │  Query: start_time <= 10.0 AND end_time > 10.0
       │             │  Result: video_id="aaa" ✅
t=12s  └─────────────┘  video_ended("aaa")
         │
         │ UPDATE SequenceVideoResult SET end_time=12.0 WHERE video_id="aaa" ✅
         │ INSERT SequenceVideoResult (video_id="bbb", start_time=12.0) ✅
         │
       ┌─────────────┐
       │  Video B    │  SequenceVideoResult: start_time=12.0 ✅
       │  Plays      │
t=15s  │             │  Detection at t=15.0
       │             │  Query: start_time <= 15.0 AND end_time > 15.0
       │             │  Result: video_id="bbb" ✅
t=20s  │             │  Detection at t=20.0
       │             │  Query: start_time <= 20.0 AND end_time > 20.0
       │             │  Result: video_id="bbb" ✅
       └─────────────┘
```

│                                    │                                         │
│                                    ▼                                         │

│  │   - Use timestamp result for video_id ✅                            │    │
