## Root Cause Analysis

### 1. WebSocket Endpoint Implementation (CRITICAL BUG)

**Location**: `/home/rigade/Testing/ai-model-validation-platform/backend/main.py:4061-4083`

**Current Implementation**:
```python
@app.websocket("/ws/test-sessions/{session_id}/detections")

    """WebSocket endpoint for real-time detection events during HIL testing"""
    await websocket.accept()
    logger.info(f"🔌 WebSocket connected for test session detections: {session_id}")

    try:
        while True:
            # Keep connection alive and send heartbeat
            data = await websocket.receive_text()
            logger.debug(f"📨 Received WebSocket data for {session_id}: {data}")

            # Echo back or send detection events
            await websocket.send_json({
                "type": "heartbeat",
                "session_id": session_id,
                "timestamp": datetime.now().isoformat()
            })
    except Exception as e:

    finally:
        logger.info(f"🔌 WebSocket disconnected for test session: {session_id}")
```

**CRITICAL BUGS IDENTIFIED**:

#### Bug #1: No Detection Event Broadcasting
- **Issue**: Endpoint only sends heartbeat messages, never actual detection events
- **Line**: 4074 - Only sends `{"type": "heartbeat"}`
- **Impact**: 100% detection data loss - frontend receives zero detection events
- **Severity**: CRITICAL

#### Bug #2: Blocking Receive Loop
- **Issue**: `await websocket.receive_text()` blocks execution waiting for client messages
- **Line**: 4070
- **Impact**: Detection events generated by LabJack service cannot be sent because the loop is blocked waiting for incoming messages
- **Pattern**: This is a **blocking consumer pattern** when it should be a **broadcaster pattern**

#### Bug #3: No Integration with Detection Service
- **Issue**: No connection to `LabJackDetectionMonitor` or detection event emission system
- **Missing**: No callback registration, no event queue, no bridge between detection service and WebSocket
- **Impact**: Detection events are generated and stored in DB but never reach the WebSocket layer

@app.websocket("/ws/test-sessions/{session_id}/detections")
async def websocket_test_session_detections(websocket: WebSocket, session_id: str):
    """WebSocket endpoint for real-time detection events during HIL testing"""
    await websocket.accept()
    logger.info(f"🔌 WebSocket connected for test session detections: {session_id}")

    # Register this WebSocket connection with detection service
    detection_monitor = get_detection_monitor()

    # Create async callback for this specific connection
    async def send_detection_to_client(detection_data: dict, event_session_id: str):
        """Send detection event to this WebSocket client"""
        if event_session_id == session_id:  # Filter by session
            try:
                await websocket.send_json({
                    "type": "detection_event",
                    "data": detection_data
                })
                logger.debug(f"📤 Sent detection {detection_data['id']} to client")
            except Exception as e:
                logger.warning(f"Failed to send detection to client: {e}")

    # Register callback with detection monitor
    detection_monitor.set_websocket_emit_function(send_detection_to_client)
    logger.info(f"✅ Registered WebSocket emission callback for session {session_id}")

    try:
        # Non-blocking keep-alive loop
        while True:
            try:
                # Use wait_for with timeout to prevent blocking
                data = await asyncio.wait_for(websocket.receive_text(), timeout=30.0)
                logger.debug(f"📨 Received WebSocket data for {session_id}: {data}")

                # Send heartbeat response
                await websocket.send_json({
                    "type": "heartbeat",
                    "session_id": session_id,
                    "timestamp": datetime.now().isoformat()
                })
            except asyncio.TimeoutError:
                # Send periodic heartbeat even if no client messages
                await websocket.send_json({
                    "type": "heartbeat",
                    "session_id": session_id,
                    "timestamp": datetime.now().isoformat()
                })
    except WebSocketDisconnect:
        logger.info(f"🔌 WebSocket disconnected for test session: {session_id}")
    except Exception as e:
        logger.error(f"❌ WebSocket error for {session_id}: {e}")
    finally:
        # Cleanup: Unregister callback
        detection_monitor.set_websocket_emit_function(None)
        logger.info(f"🧹 Unregistered WebSocket callback for session {session_id}")
```

                "type": "detection_event",

@app.get("/api/test-sessions/{session_id}/detections/stream")
async def stream_detections_polling(
    session_id: str,
    since_timestamp: Optional[float] = Query(None),
    db: Session = Depends(get_db)
):
    """HTTP polling fallback for detection events"""
    query = db.query(DetectionEvent).filter(
        DetectionEvent.test_session_id == session_id
    )

    if since_timestamp:
        query = query.filter(DetectionEvent.timestamp > since_timestamp)

    events = query.order_by(DetectionEvent.timestamp).limit(100).all()

    return {
        "detections": [event.to_dict() for event in events],
        "count": len(events),
        "timestamp": time.time()
    }
```
